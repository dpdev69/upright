Hardware support

The MX Vertical is the only mouse verified on real hardware. Other models are built from published device data and tested against Upright's mouse simulator, so they're expected to work but aren't verified. Upright only diverts buttons while it runs and writes nothing permanent to a mouse: quit it, or switch the mouse off and on, and its buttons return to factory behavior.

Unsigned builds

Release builds are ad-hoc signed and not notarized by Apple, so macOS asks you to confirm the first launch. Download Upright only from its GitHub releases, or build it yourself from the source.
