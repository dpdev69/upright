Upright vs OpenLogi

Checked 20 October 2026 · Facts from each project's README and site

Both apps remap Logitech buttons over HID++ and both are open source. Choose OpenLogi if you want more than a mouse tool: it also handles Logitech keyboards, Litra lights and webcams, runs on Linux and Windows too, and, per its README, ships a notarized macOS build, though that README also says it is still under active development. Choose Upright if you only need your Logitech mouse's buttons remapped on a Mac, want a smaller scope, and don't mind confirming the first launch.

Upright

Upright is a small native menu-bar app that talks to Logitech mice directly over HID++ 2.0, the protocol Logitech's own software uses. That lets it take over buttons generic remappers often can't see, such as the top (DPI), gesture and SmartShift buttons. It adds gestures (a click plus hold-and-move in four directions, five actions per button), per-app profiles, several mice at once with a setup for each model, pointer speed (DPI) presets, Easy-Switch from a button, battery alerts at 15% and 5%, and export and import of every mapping. It has no account, no analytics and no telemetry, and nothing is written to the mouse's memory: quit it and the buttons go back to factory behavior.

Honest limits: it works only with Logitech HID++ mice and does nothing for keyboards, lights or webcams. Only the MX Vertical has been verified on real hardware so far. It needs macOS 13 or later, and it is ad-hoc signed and not notarized, so macOS blocks the first launch (see the FAQ below).

OpenLogi

OpenLogi is an open-source, local-first alternative to Logi Options+, written in Rust (openlogi.org). Per its README it runs on macOS 13 or later, Linux and Windows, and reads devices on Bolt and Unifying receivers, Bluetooth or a cable. For mice it remaps buttons, with gestures on supported buttons, short-press and long-press actions and an Actions Ring overlay, and it controls DPI and SmartShift. It switches profiles per app on macOS and Windows, keeps its settings in one TOML file and comes with a command-line tool. Beyond mice, its README lists keyboard F-key remapping and RGB, Litra lights and Logitech webcams. It says there is no account and no telemetry.

The catch, in its own words: the README opens with a warning that OpenLogi is under active development and not yet stable, and features and config may still change. The latest release when we checked was 0.8.14 on 15 October 2026, and the project releases often. The README does not publish a list of mice verified on hardware. Its macOS build is described as a signed, notarized .dmg, with a Homebrew cask as the other install path.

Which should you pick?

  • You also want to configure a Logitech keyboard, Litra light or webcam: OpenLogi. Upright is for mice only.
  • You use Linux or Windows as well as a Mac: OpenLogi. Upright is macOS only.
  • You want a macOS build that opens without the extra confirmation: OpenLogi, going by its README. Upright is not notarized yet.
  • You want a script-friendly, plain-text config: OpenLogi, with its TOML file and command-line tool.
  • You have an MX Vertical and want a mouse-only tool that has been run on that exact mouse: Upright. It is the one model Upright has verified on hardware.
  • You want a smaller tool with a fixed scope: Upright. It remaps Logitech mouse buttons and adds pointer speed, scrolling and battery features, and nothing else.

Either way, quit Logi Options+ first, and don't run the two apps on the same mouse at once.

FAQ

Is OpenLogi free?

Yes, as far as its own pages say. The code is open source, dual-licensed under Apache-2.0 or MIT per its README, and neither the README nor openlogi.org lists a price. Upright is free and MIT-licensed.

Which mice does OpenLogi support?

Its README says Logitech mice, keyboards, Litra lights and webcams, over HID++ and UVC, and it publishes no list of verified models. Its first release notes, from 30 May 2026, said only the MX Master 4 had been tested on real hardware. Upright's catalog covers mice only, and only the MX Vertical is verified on hardware.

Which one is easier to open the first time?

OpenLogi. Its README says the macOS .dmg is signed and notarized. Upright is ad-hoc signed and not notarized, so macOS blocks the first launch. On macOS 15 or later, try to open it once, then go to System Settings, Privacy & Security and click Open Anyway. On macOS 13 and 14 you can right-click it and choose Open.

Can I run Upright and OpenLogi together?

Not on the same mouse. Both talk to Logitech mice over HID++, and only one app can own a mouse's buttons at a time. OpenLogi's README tells you to quit Logi Options+ first for the same reason. Quit one before you open the other.
